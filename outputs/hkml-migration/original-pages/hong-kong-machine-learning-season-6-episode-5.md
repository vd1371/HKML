## Programme:

Talk 1: Applications of LLMs at Maven Securities

We were given the opportunity to get a sneak peek into Maven Securities' efforts with Large Language Models.

Talk 2: Machine Learning Tools for Asset Management: A Guided Tour

We got a guided tour of useful machine learning tools and how they can be used for asset management (systematic, semi-systematic, and discretionary).

Talk 3: Semantic Textual Similarity: Extracting Greater Value from Text Data

Abstract: Semantic Textual Similarity (STS) is a crucial task in natural language processing that quantifies the semantic relatedness between text fragments. This work presents an analysis of fundamental similarity functions and introduces a novel multiobjective approach for optimal threshold selection in STS tasks. The authors explore the strengths and limitations of commonly used similarity measures and propose a multiobjective optimization framework to determine the most suitable threshold to extract greater value from the text data.

Speaker: Boris Kriuk is co-Founder and CEO at Sparcus Technologies, Deep Learning Researcher, Scientific Member at the Computer Vision Foundation and the Association for Computing Machinery.
